## คำสั่งที่ทดสอบได้

- กินกาแฟ 80 → บันทึกรายจ่าย 80 บาท หมวดอาหาร
- จ่าย ค่าอาหาร 125 → บันทึกรายจ่าย 125 บาท
- เติมน้ำมัน 500 → บันทึกรายจ่าย 500 บาท
- รับ เงินเดือน 35000 → บันทึกรายรับ 35,000 บาท
- รับจากลูกค้า 2500 → บันทึกรายรับ 2,500 บาท
- ตั้งงบ อาหาร 5000 → ตั้งงบอาหารเดือนปัจจุบันตามเวลาไทย
- เพิ่มหมวดรายจ่าย สัตว์เลี้ยง / ลบหมวดรายจ่าย สัตว์เลี้ยง → จัดการหมวดตามสิทธิ์
- ค้นหารายการ กาแฟ → ค้นหารายการในบัญชีที่มีสิทธิ์
- แก้รายการ 42 เป็น 180 / ลบรายการ 42 → ใช้ ID จากผลรายการ และต้องมีสิทธิ์จัดการ
- เตือน จ่ายค่าเน็ต ทุกเดือนวันที่ 25 เวลา 09:00 → วันที่ 25 เวลา 09:00 ตาม Asia/Bangkok
- เตือน ประชุม พรุ่งนี้ 10:00 → เตือนครั้งเดียว
- โน้ต เรื่องที่ต้องจำ / งาน ส่งรายงาน / เก็บ https://example.com / ค้นหา ใบเสร็จ → ฟีเจอร์โน้ต งาน และคลังเดิม
- ส่งใบเสร็จ → ตรวจผลวิเคราะห์ แล้วพิมพ์ ยืนยันค่าใช้จ่าย
- ส่งเสียง → ตรวจข้อความ แล้วพิมพ์ ยืนยันเสียง
