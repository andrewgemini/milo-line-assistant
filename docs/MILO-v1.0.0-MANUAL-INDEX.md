# Milo v1.0.0 — คู่มือการใช้งาน

เอกสารคู่มืออย่างเป็นทางการของ Milo Production แบ่งเป็น 2 ส่วน

## คู่มือผู้ใช้งาน

ไฟล์: `docs/USER-MANUAL-v1.0.0.md`

ครอบคลุมการใช้งานผ่าน LINE และ Dashboard ได้แก่

- จดรายรับ/รายจ่ายจากข้อความ
- อ่านสลิปและใบเสร็จจากรูป
- จดจากเสียง
- อ่าน PDF
- สรุปและวิเคราะห์การเงิน
- หมวดและงบประมาณ
- รายการประจำและ Reminder
- โน้ต/งาน/คลัง
- Group Accounting
- Export CSV/Excel/PDF
- สิทธิ์ Free / Pro / Pro Max
- คำสั่งทางลัดและ Troubleshooting เบื้องต้น
