# Milo v1.2.2 — Receipt Completeness

## Summary

ปรับระบบอ่านใบเสร็จให้เก็บรายละเอียดครบขึ้น โดยเฉพาะใบเสร็จร้านอาหาร/POS ที่มีหัวร้าน เลขที่ใบเสร็จ ตารางสินค้า จำนวน ยอดรวม และวิธีชำระเงิน

## Improvements

- อ่านชื่อร้านจากหัวใบเสร็จและไม่ใช้ช่อง `ประเภท / พนักงาน / เวลา` เป็นชื่อร้าน
- อ่าน `เลขที่ใบเสร็จ` จาก `เลขที่:` / Receipt No.
- อ่านวิธีชำระ เช่น เงินสด, QR/พร้อมเพย์, บัตร และโอนเงิน
- อ่านรายการสินค้าในตาราง POS ได้หลายแถว พร้อมจำนวนและยอดต่อแถว
- รองรับ OCR ที่แยกชื่อสินค้าออกจากจำนวน/ราคาไปคนละบรรทัด
- แยก `ยอดรวม/ทั้งหมด/เงินสด/เงินทอน/footer` ออกจากรายการสินค้า
- แก้กรณี `ยอดรวม 9 423.00` ไม่ให้ตีจำนวนสินค้า 9 เป็นยอดเงิน
- แสดงรายการสินค้าในข้อความตรวจสอบได้สูงสุด 10 แถว พร้อมแจ้งจำนวนที่เหลือ
- เพิ่ม Vision receipt-detail repair รอบเฉพาะ เมื่อผลรอบแรกอ่านชื่อร้าน/เลขที่/รายการสินค้าไม่ครบ
- แก้ prompt สำหรับ focused date repair ที่เคยมีข้อความ encoding ผิด

## Regression case

เพิ่มชุดทดสอบใบเสร็จร้านอาหารยอด 423 บาท รูปแบบเดียวกับเคส Production ที่รายงาน โดยตรวจ:

- merchant
- receipt number
- วันที่/เวลา
- payment method
- grand total
- รายการสินค้า 7 แถว

ระบบยังคงให้ผู้ใช้ตรวจและยืนยันก่อนบันทึกธุรกรรมจริง
