## คำสั่งสำคัญที่เพิ่มใน v1.1.0

```text
รายการเตือน
ยกเลิกเตือน #7

ดูงาน
งานทั้งหมด
เสร็จงาน #9

ลงปฏิทิน ประชุมทีมพรุ่งนี้ 10:30
ดูปฏิทิน
ยกเลิกนัด #12

สถานะคลัง
ผู้ช่วยกลุ่ม
```

ใน LINE Group ให้เรียกข้อความคำสั่งด้วย `@ไมโล` เช่น:

```text
@ไมโล รายการเตือน
@ไมโล ดูงาน
@ไมโล ค้นหา ใบเสนอราคา
@ไมโล ลงปฏิทิน ประชุมทีมพรุ่งนี้ 10:30
@ไมโล แจ้งส่งงานด้วยถึง @สมชาย
```

## หมายเหตุ Calendar

Milo เก็บ Calendar Event ภายในระบบ และสร้างลิงก์สำหรับเพิ่มเข้า Google Calendar รวมถึงไฟล์ `.ics` สำหรับ Apple Calendar/Outlook โดยไม่ขอสิทธิ์ OAuth เกินความจำเป็น
