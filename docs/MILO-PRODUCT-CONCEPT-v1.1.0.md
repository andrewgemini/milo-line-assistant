# Milo v1.1 — Chat-First Personal Assistant

## Product Concept

**Milo = ผู้ช่วยส่วนตัวใน LINE ที่ “เตือน · เก็บ · จัดการ · จดเงิน” ได้ในแชทเดียว**

ผู้ใช้ไม่ต้องเรียนรู้ฟอร์ม ไม่ต้องสลับหลายแอป และไม่ต้องจำเมนูซับซ้อน เพียงพิมพ์บอก Milo เหมือนคุยกับเพื่อน ทั้งในแชทส่วนตัวและกลุ่ม LINE

## 1. 🔔 Reminder

ตัวอย่างคำสั่ง:

```text
เตือนประชุมพรุ่งนี้ 10:00
เตือนดื่มน้ำทุก 30 นาที
เตือนส่งรายงานทุกวัน 17:00
เตือนประชุมทีมทุกสัปดาห์วันจันทร์ 09:00
เตือนจ่ายค่าเช่าทุกเดือนวันที่ 1 09:00
```

รองรับการเตือนครั้งเดียว รายวัน รายสัปดาห์ รายเดือน และทุก N นาที รวมถึงอ่านวัน/เวลาจากรูปแล้วสร้าง Reminder หลังผู้ใช้ตรวจและยืนยัน

## 2. 🗂️ Vault — เก็บและค้นคืน

ตัวอย่าง:

```text
เก็บ https://example.com/brief #งาน #สำคัญ
เก็บ รหัส Wi-Fi ห้องประชุม ABC123
ค้นหา ใบเสนอราคา
สถานะคลัง
```

- ข้อความและลิงก์เก็บในฐานข้อมูล
- รูป/ไฟล์ถูกสำรองเข้า object storage เมื่อ storage พร้อมใช้งาน
- ระบบแสดงสถานะอย่างตรงไปตรงมา หาก media ใดสำรองถาวรไม่สำเร็จจะบอกให้ส่งใหม่
- ในกลุ่ม LINE การค้นหาจะค้นเฉพาะคลังของกลุ่มนั้น เพื่อไม่ปะปนข้อมูลส่วนตัว

> คำว่า “เก็บถาวร” ของ media ใช้เมื่อระบบได้รับ `storageKey` สำเร็จ และหมายถึงเก็บไว้จนกว่าผู้ใช้จะลบ ภายใต้นโยบาย retention ของ storage provider

## 3. 👥 Group LINE Assistant

เพิ่ม Milo เข้า LINE Group แล้วเรียกด้วย `@ไมโล` สำหรับคำสั่งข้อความ เพื่อไม่ให้บอตตอบทุกข้อความในกลุ่ม

```text
@ไมโล เตือนส่งรายงานพรุ่งนี้ 09:00
@ไมโล เก็บ https://example.com/spec #โครงการ
@ไมโล ค้นหา ใบเสนอราคา
@ไมโล ลงปฏิทิน ประชุมทีมพรุ่งนี้ 10:00
@ไมโล แจ้งส่งงานด้วยถึง @สมชาย
@ไมโล งาน ตรวจเอกสารลูกค้า
```

ฟังก์ชันกลุ่มประกอบด้วย Reminder, shared vault/search, calendar, To-do, mention/tag และ group finance ตามสิทธิ์แพ็กเกจ/สมุดบัญชี

## 4. ✅ Life & Work Management

### To-do

```text
งาน ส่งสรุปรายสัปดาห์
งาน โทรหาลูกค้า
```

### Note

```text
โน้ต รหัส Wi-Fi ห้องประชุม
```

### Quick Search

```text
ค้นหา ใบเสร็จ
หาไฟล์ proposal
```

### Calendar

```text
ลงปฏิทิน ประชุมทีมพรุ่งนี้ 10:30
นัดหมอ วันที่ 20/09/2569 14:00 ถึง 15:30
ดูปฏิทิน
ยกเลิกนัด 12
```

Milo สร้าง event ใน Milo Calendar และส่งลิงก์:

- **Google Calendar** — กดเพื่อเปิดหน้า Add Event ที่กรอกวัน/เวลา/ชื่อไว้แล้ว
- **Apple Calendar / Outlook / แอปที่รองรับ ICS** — ดาวน์โหลดไฟล์ `.ics` แบบ signed URL

เวอร์ชันนี้ยังไม่เขียนลง Google Calendar account แบบ background OAuth โดยอัตโนมัติ เพราะต้องให้เจ้าของบัญชีอนุญาต OAuth ก่อน

## 5. 💰 Conversational Finance

ตัวอย่าง:

```text
กินกาแฟ 80
เติมน้ำมัน 800
เงินเดือนเข้า 35000
ตั้งงบ อาหาร 5000
สรุปวันนี้
สรุปสัปดาห์นี้
สรุปเดือนนี้
วิเคราะห์เดือนนี้
ยกเลิกรายการล่าสุด
```

รองรับ Text, Voice, Receipt/Slip Image และ PDF พร้อมหมวด งบประมาณ รายการประจำ รายงาน Export และ Group Accounting ตามสิทธิ์

## Core UX Principle

แทนที่จะบังคับผู้ใช้กรอก:

`วันที่ → ประเภท → หมวด → จำนวนเงิน → หมายเหตุ → บันทึก`

Milo ใช้แนวคิด:

> **“บอก Milo ไปเลยว่าเกิดอะไรขึ้น หรืออยากให้ช่วยอะไร”**

แล้วระบบจัดโครงสร้างข้อมูลด้านหลังให้

## Data Boundaries

- แชทส่วนตัว: Vault/Calendar/Finance ใช้ข้อมูลในขอบเขตของผู้ใช้
- กลุ่ม LINE: Vault/Calendar/Reminder ใช้ `lineChatId` ของกลุ่มเป็นขอบเขต
- Group Finance: ต้องเปิดสมุดบัญชีกลุ่มและกำหนด role ก่อน
- ข้อความกลุ่ม: ต้องเรียก `@ไมโล` สำหรับ text command
- LINE User ID ไม่เปิดเผยในกลุ่มผ่านคำสั่ง `ไอดี`; ต้องขอจากแชทส่วนตัว

## Product Pillars

**🔔 เตือน** → บอกว่าอยากให้เตือนอะไร เมื่อไหร่

**🗂️ เก็บ** → ส่งมา แล้ว Milo เก็บและหาให้ภายหลัง

**👥 กลุ่ม** → ดึง Milo เข้ากลุ่ม ให้ช่วยทีมโดยไม่ปะปนข้อมูลส่วนตัว

**✅ จัดการ** → To-do, Note, Search, Calendar ในแชทเดียว

**💰 เงิน** → พิมพ์ พูด หรือส่งหลักฐาน แล้ว Milo จดและสรุปให้
