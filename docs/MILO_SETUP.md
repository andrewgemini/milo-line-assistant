# คู่มือไมโล: บัญชีการเงิน กลุ่ม LINE และสิทธิ์

ไมโลแยกข้อมูลการเงินด้วย **สมุดบัญชี** เพื่อให้รายการส่วนตัวไม่ถูกนำไปแสดงในกลุ่มโดยอัตโนมัติ ทุกธุรกรรม รูปใบเสร็จ สลิป ไฟล์เสียง หมวด งบ ยอดเริ่มต้น รายการประจำ รายงาน และไฟล์ส่งออกจะผูกกับสมุดบัญชีที่เลือกเสมอ

| ประเภทสมุดบัญชี | การใช้งาน | การแชร์ข้อมูล |
|---|---|---|
| บัญชีส่วนตัว | ค่าเริ่มต้นของผู้ใช้ที่เชื่อม LINE | ไม่แชร์กับกลุ่ม |
| บัญชีกลุ่ม | ใช้บันทึกรายการที่กลุ่มยอมรับร่วมกัน | เห็นเฉพาะสมาชิกที่ได้รับสิทธิ์ |

## เปิดใช้บัญชีกลุ่ม LINE

1. เชื่อมบัญชี LINE ส่วนตัวกับไมโลก่อน และเพิ่มไมโลเข้าในกลุ่ม LINE ที่ต้องการใช้งาน
2. เปิด dashboard แล้วเลือกเมนู **กลุ่ม LINE** จากนั้นสร้างบัญชีกลุ่มโดยเลือกเฉพาะกลุ่มที่ไมโลตรวจพบ
3. เจ้าของเพิ่มสมาชิกจากรายชื่อที่ตรวจพบในกลุ่มเดียวกัน และกำหนดสิทธิ์ตามความจำเป็น
4. สลับสมุดบัญชีจากตัวเลือกด้านบนของ dashboard ก่อนดูรายงาน บันทึกรายการ หรือจัดการงบของกลุ่ม

> การสร้างบัญชีกลุ่มหรือเพิ่มสมาชิกไม่สร้างธุรกรรมการเงินใหม่ และการบันทึกจากรูปหรือเสียงยังต้องได้รับการยืนยันอย่างชัดเจนก่อนเสมอ

## สิทธิ์สมาชิกสมุดบัญชี

| สิทธิ์ | ดูข้อมูล | เพิ่มรายการ | แก้ไข/ลบ/ตั้งค่า | จัดการสมาชิก |
|---|---:|---:|---:|---:|
| `viewer` | ได้ | ไม่ได้ | ไม่ได้ | ไม่ได้ |
| `contributor` | ได้ | ได้ | ไม่ได้ | ไม่ได้ |
| `manager` | ได้ | ได้ | ได้ | ไม่ได้ |
| `owner` | ได้ | ได้ | ได้ | ได้ |

การเปลี่ยนสิทธิ์สมาชิกทำได้โดย `owner` เท่านั้น และเพิ่มได้เฉพาะสมาชิกที่ไมโลตรวจพบแล้วในกลุ่ม LINE เดียวกัน ข้อมูลของผู้ที่ไม่มี membership จะถูกปฏิเสธที่ API ก่อนอ่านธุรกรรมหรือหลักฐานไฟล์

## จัดการธุรกรรมและหลักฐาน

บน dashboard ใช้เมนู **รายการธุรกรรม** เพื่อค้นหาจากประเภท จำนวนเงิน หมวด หรือหมายเหตุ และเปิดดูหลักฐานที่อยู่ในแถวเดียวกันได้ ตารางแบ่งหน้าละ 20 รายการและกรองเฉพาะสมุดบัญชีที่เลือก ใบเสร็จ สลิป และไฟล์เสียงจะปรากฏก็ต่อเมื่อมีการเชื่อมหลังการยืนยันรายการเรียบร้อยแล้ว

เมนู **คลังไฟล์** พาไปยังแผงจัดการ metadata ซึ่งค้นหาจากชื่อไฟล์ แท็ก หรือลิงก์ได้ กดปุ่ม “จัดการ” เพื่อเปิด dialog แก้แท็กหรือลิงก์ โดยไฟล์ต้นฉบับในคลัง S3 จะไม่ถูกแก้ไข

## รายงานและการส่งออก

รายงานวัน สัปดาห์ เดือน และปีแสดงยอดจากสมุดบัญชีที่เลือก และเปรียบเทียบกับช่วงก่อนหน้าจากข้อมูลจริง หากช่วงก่อนหน้าเป็นศูนย์ ไมโลจะแสดงส่วนต่างเป็นจำนวนเงินแต่ไม่สร้างเปอร์เซ็นต์ขึ้นมาเอง CSV, Excel และ PDF ใช้เฉพาะธุรกรรมจริงในขอบเขตสมุดบัญชีเดียวกัน
