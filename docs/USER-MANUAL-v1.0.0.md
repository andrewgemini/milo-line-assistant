# คู่มือผู้ใช้งาน Milo v1.0.0

คู่มือนี้สำหรับผู้ใช้ทั่วไปที่ใช้งาน Milo ผ่าน LINE และผู้ใช้ที่เข้าดูข้อมูลของตนเองผ่าน Dashboard

## 1. Milo คืออะไร

Milo เป็นผู้ช่วยการเงินบน LINE ที่ช่วยจดรายรับ รายจ่าย อ่านสลิป/ใบเสร็จจากรูป ถอดเสียง วิเคราะห์ PDF สรุปการเงิน ตั้งงบ ตั้งรายการประจำ ตั้งการเตือน จัดหมวด ค้นหารายการ เก็บโน้ต/ไฟล์ และส่งออกข้อมูล

แนวคิดหลักคือ ผู้ใช้ไม่จำเป็นต้องกรอกฟอร์มบัญชีทีละช่อง เพียงพิมพ์ข้อความตามภาษาปกติ เช่น `กินกาแฟ 80` แล้ว Milo จะแยกข้อมูลและบันทึกให้

---

## 2. เริ่มต้นใช้งาน

### 2.1 เพิ่ม Milo เป็นเพื่อนใน LINE

เปิดห้องแชทกับ Milo แล้วพิมพ์

`สวัสดีไมโล`

หรือ

`วิธีใช้งาน`

Milo จะแสดงเมนูและทางลัดที่ใช้งานได้

### 2.2 ดู LINE User ID ของตนเอง

ในแชทส่วนตัวกับ Milo พิมพ์

`ไอดี`

Milo จะตอบ LINE User ID ที่ขึ้นต้นด้วย `U` และตามด้วยอักขระ 32 ตัว ใช้รหัสนี้เมื่อต้องการเชื่อมกับ Dashboard

เพื่อความเป็นส่วนตัว คำสั่ง `ไอดี` จะส่งรหัสกลับเฉพาะในแชทส่วนตัว ไม่แสดงในกลุ่ม

## 3. จดรายรับและรายจ่าย

### 3.1 จดรายจ่ายแบบภาษาปกติ

ตัวอย่าง

- `กินกาแฟ 80`
- `ซื้อข้าว 65`
- `ค่าน้ำมัน 1200`
- `จ่าย ค่าอาหาร 125`

Milo จะตรวจจำนวนเงิน รายการ และหมวดให้อัตโนมัติ

### 3.2 จดรายรับ

ตัวอย่าง

- `เงินเดือนเข้า 35000`
- `ขายของได้ 1500`
- `รับเงินเดือน 30000`
- `รายรับ โบนัส 5000`

### 3.3 หลังบันทึก

หลังบันทึกสำเร็จ Milo จะแสดงการ์ดสรุป เช่น

- จำนวนเงิน
- หมวด
- วันที่/เวลา
- รายรับ/รายจ่ายของวัน
- งบที่ใช้ไป หากมีการตั้งงบ

ระบบมี Duplicate Protection เพื่อลดความเสี่ยงจากการส่งข้อความหรือหลักฐานเดิมซ้ำ

## 4. ยกเลิก แก้ไข และลบรายการ

### 4.1 ยกเลิกรายการล่าสุด

พิมพ์

`ยกเลิกรายการล่าสุด`

หรือ

`undo`

ระบบจะ soft-delete รายการล่าสุดและเก็บประวัติไว้ใน Audit log

### 4.2 ค้นหารายการ

ตัวอย่าง

`ค้นหารายการ กาแฟ`

`หารายการ 500`

Milo จะแสดงหมายเลขรายการ เช่น `#25`

### 4.3 แก้ยอดของรายการ

ตัวอย่าง

`แก้รายการ #25 เป็น 120 บาท`

### 4.4 ลบรายการตามหมายเลข

ตัวอย่าง

`ลบรายการ #25`

การลบเป็นแบบตรวจสอบย้อนหลังได้ ไม่ลบประวัติการทำรายการแบบไร้ร่องรอย

## 5. อ่านสลิปและใบเสร็จจากรูป

### 5.1 วิธีใช้งาน

1. ส่งรูปสลิปหรือใบเสร็จใน LINE
2. Milo จะแจ้งว่าได้รับรูปและกำลังวิเคราะห์
3. ระบบอ่านยอด ร้านค้า วันที่ เวลา และหมวดที่เป็นไปได้
4. ตรวจข้อมูลที่ Milo เสนอ
5. กดปุ่มยืนยัน หรือพิมพ์ `ยืนยันค่าใช้จ่าย`

### 5.2 แก้ข้อมูลก่อนบันทึก

ถ้าข้อมูลจาก OCR ไม่ถูกต้อง สามารถแก้ได้ก่อนยืนยัน เช่น

- `แก้ใบเสร็จ ยอด 75 บาท`
- `แก้ใบเสร็จ หมวด อาหาร`
- `แก้ใบเสร็จ วันที่ 14/09/2569`
- `แก้ใบเสร็จ ร้านค้า ร้านกระเพรากลางซอย`
- `แก้ใบเสร็จ หมายเหตุ มื้อกลางวัน`

จากนั้นพิมพ์

`ยืนยันค่าใช้จ่าย`

### 5.3 กรณีวันที่อ่านไม่ชัด

ถ้า OCR อ่านวันที่ไม่ได้ แต่เวลาในใบเสร็จชัดและใกล้กับเวลาส่งรูป ระบบสามารถใช้อ้างอิงวันที่ส่งรูปอย่างปลอดภัยพร้อมบันทึกหมายเหตุไว้

ถ้าวันที่และเวลายังไม่น่าเชื่อถือ Milo จะไม่เดาเอง และจะขอให้ระบุวันที่ เช่น

`ยืนยันค่าใช้จ่าย วันที่ 27/08/2569`

---

## 6. จดจากข้อความเสียง

### 6.1 วิธีใช้งาน

1. ส่ง Voice Message ใน LINE เช่นพูดว่า “กินข้าว 120 บาท”
2. Milo จะตอบรับทันทีว่ากำลังถอดเสียง
3. เมื่อเสร็จ ระบบจะแสดงข้อความที่ถอดได้และข้อเสนอรายรับ/รายจ่าย
4. ตรวจข้อมูลแล้วกด `ยืนยันบันทึก` หรือพิมพ์ `ยืนยันเสียง`

### 6.2 แก้ไขข้อความเสียงก่อนบันทึก

พิมพ์

`แก้ไขข้อความเสียง`

หรือระบุข้อความใหม่โดยตรง เช่น

`แก้ไขเสียง จ่ายกาแฟ 65 บาท`

เปลี่ยนหมวดได้ เช่น

`เปลี่ยนหมวดเสียง อาหาร`

## 7. จดจาก PDF

ฟีเจอร์ PDF ใช้สำหรับแพ็กเกจ Pro Max

### วิธีใช้งาน

1. ส่งไฟล์ `.pdf` ใน LINE
2. Milo จะอ่านรายการที่พบและแสดงตัวอย่าง
3. ตรวจข้อมูล
4. พิมพ์ `ยืนยัน PDF`

ระบบจะบันทึกเฉพาะรายการที่มียอดและวันที่ชัดเจน รายการที่ข้อมูลไม่พอจะถูกข้ามเพื่อป้องกันข้อมูลผิด

## 22. ถ้า Milo ไม่เข้าใจคำสั่ง

## 23. ข้อควรระวัง

1. ตรวจยอด วันที่ ร้านค้า และหมวดก่อนยืนยันรายการจาก OCR/PDF
2. อย่าส่ง LINE User ID ของตนเองในกลุ่มสาธารณะ
3. ถ้าส่งหลักฐานเดิมซ้ำ ให้ตรวจรายการก่อนบันทึก แม้ระบบมี Duplicate Protection
4. การลบรายการใช้ soft-delete เพื่อให้ตรวจสอบย้อนหลังได้
5. ถ้าอ่านรูปไม่ชัด ให้ถ่ายใหม่ให้เห็นยอด วันที่ เวลา และชื่อร้านครบ
6. เวลาในระบบอ้างอิง Asia/Bangkok
